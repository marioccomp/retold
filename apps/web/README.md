# Retold - Em desenvolvimento

Retold é uma **plataforma em desenvolvimento para desenvolvedores e criadores de software construírem portfólios visuais e interativos** que mostrem seus projetos de forma clara e envolvente. Em vez de um currículo tradicional ou uma lista de repositórios, aqui você pode criar uma vitrine visual dos seus projetos com imagens, vídeos, descrições e links funcionais — ajudando talentos a serem encontrados por recrutadores e clientes.
