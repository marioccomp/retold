# Project Overview: 15

## 📋 Overview
This project is a Java-based backend application designed to convert values between currencies using the Exchange API. Its main purpose is to provide a simple currency exchange service.

## 🏗️ Architecture
**Style:** Monolith
The application follows a monolithic architecture, with a single Java-based backend handling all currency exchange logic, and relies on an external API for exchange rate data.

## ✅ Strengths
- The application has a clear and focused purpose, making it easy to understand and maintain.
- It utilizes a widely-used build tool, Maven, for dependency management and project structure.
- The README provides straightforward instructions for setup and usage.

## ⚠️ Areas for Improvement
- The lack of testing framework and test files makes it difficult to ensure the application's reliability and catch bugs.
- The absence of Docker and CI/CD pipelines hinders the application's scalability, deployability, and maintainability.
- The project's structure and max depth suggest potential complexity issues that could be addressed with a more modular design.

## 📊 Maturity Level
**Level:** Prototype
The application is considered a prototype due to its limited functionality, lack of testing and deployment infrastructure, and overall simplicity, indicating it is not yet ready for production use.
