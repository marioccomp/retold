# Project Overview: 14

## 📋 Overview
This project is a Java-based backend application designed to convert values between currencies using the Exchange API. Its main purpose is to provide a simple currency exchange functionality.

## 🏗️ Architecture
**Style:** Monolith
The application follows a monolithic architecture, with a single Java-based backend handling all the logic, and it relies on an external API for exchange rates, indicating a straightforward and simple data flow.

## ✅ Strengths
- The project has a clear and focused purpose, making it easy to understand and maintain.
- It provides a simple and concise README file with instructions on how to set up and use the application.
- The use of Maven as a build tool simplifies the dependency management and build process.

## ⚠️ Areas for Improvement
- The lack of testing framework and test files makes it difficult to ensure the application's reliability and stability.
- The absence of Docker and CI/CD pipelines hinders the application's scalability, deployability, and maintainability.
- The project's structure and depth could be improved with the addition of separate folders for tests, configurations, and documentation.

## 📊 Maturity Level
**Level:** Prototype
The application is assessed as a prototype due to its limited functionality, lack of testing and deployment infrastructure, and overall simplicity, indicating that it is still in the early stages of development.
