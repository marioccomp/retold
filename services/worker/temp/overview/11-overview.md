# Project Overview: 11

## 📋 Overview
This project is a clone of Tabnews, a Brazilian news platform, built for the Curso.dev website, aiming to replicate its functionality. The primary purpose is to create a full-stack application using JavaScript, React, and Next.js.

## 🏗️ Architecture
**Style:** Server-Side Rendered (SSR) and Static Site Generation (SSG) using Next.js
The architectural choice of using Next.js indicates a server-driven approach, combining the benefits of SSR and SSG, which enables efficient rendering and improved SEO, while React handles the client-side interactions.

## ✅ Strengths
- Utilizes a popular and well-maintained framework (Next.js) for building the application
- Employs Jest for testing, ensuring some level of code quality and reliability
- Includes Prettier for code formatting, promoting consistency and readability

## ⚠️ Areas for Improvement
- Lack of Docker support for containerization, which could simplify deployment and development environments
- Absence of Continuous Integration (CI) pipelines, making automated testing and deployment challenging
- Insufficient test coverage, with only one test file present, which may not adequately cover the application's functionality

## 📊 Maturity Level
**Level:** Prototype
The project is assessed as a prototype due to its limited test coverage, lack of CI/CD pipelines, and absence of containerization, indicating it is still in the early stages of development and not yet ready for production.
